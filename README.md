## THE SKETCH LAB

The interactive sketching & design-maths game lives in [`sketch-lab/`](sketch-lab/README.md).
World 08 — **The Math Playground** — teaches practical mathematics through sketching, measuring and product design.

```bash
cd sketch-lab && npm install && npm run dev
```
